# Какой ты котик? 🐈

Яркий пиксельный тест на русском: шесть шуточных вопросов, четыре фотографии в первом вопросе и **236 544 разных котика**. Графика рисуется кодом на сетке 96 × 96, без генерации изображений при прохождении.

Котик собирается строго по порядку: **тело → ушки → хвост → расцветка → мордочка → аксессуар**. Выбор ответа — черновик: рисунок меняется только после «Дальше». До расцветки котик бесцветный. Шкал на странице и сохраняемой картинке нет. Есть возврат, повторный старт, точная ссылка на результат и экспорт PNG 1080 × 1920. Белая полоска на лице Roblox исправлена.

## Посмотреть локально

Откройте `docs/index.html` в браузере. Сохраняйте всю папку `docs`, включая JavaScript, CSS и `assets`. Установка зависимостей и интернет для самого теста не нужны.

## Подключить GitHub Pages

Размещение **не включено автоматически**. Готовая статическая версия уже находится в `docs`.

1. Откройте **Settings → Pages** в репозитории.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Укажите ветку **main** и папку **/docs**, затем **Save**.
4. Дождитесь публикации и нажмите **Visit site**. Ожидаемый адрес проекта имеет вид `https://<владелец>.github.io/<имя-репозитория>/`; пока Pages не включён, это не рабочая ссылка.

Для приватного репозитория Pages требуется поддерживающий его тариф GitHub, например Pro. На GitHub Free публикация Pages доступна из публичных репозиториев. Видимость репозитория самостоятельно не менялась. Сам Pages-сайт обычно публичен даже при приватном исходном репозитории — проверяйте настройки перед включением.

Официальная инструкция: [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Изменить и пересобрать

Для сборки и всех проверок нужен Node.js 24 или новее. В проекте **нет npm-зависимостей**.

```sh
npm run build
npm test
npm run test:all
```

После изменения `src/` или `assets/` запустите сборку и закоммитьте также обновлённую папку `docs/`: именно её будет показывать Pages. Исходники и готовая версия разделены, чтобы страницу можно было опубликовать без установки сборщиков.

## Структура

- `src/` — шаблон страницы, оформление, пиксельные буквы, рендер котиков, вопросы и интерфейс.
- `assets/` — четыре предоставленные пользователем фотографии в исходном порядке.
- `scripts/build.mjs` — сборка без внешних библиотек.
- `docs/` — готовая версия для GitHub Pages; пути работают и в проектном подкаталоге.
- `tests/` — сценарии интерфейса, счётчик на SQLite и полный перебор изображений.
- `backend/` — отдельные исходники прототипа общего счётчика; **не исполняются на Pages**.
- `MONETIZATION.md` — предложения по монетизации; оплата и реклама не подключены.

## Что работает на Pages

Тест, фотографии, сборка котика, сохранение PNG, ссылки и повторные прохождения работают в браузере. Общий счётчик находок отключён явно: GitHub Pages не исполняет серверный API и не хранит такую базу. Никакие выдуманные счётчики не показываются. Для настоящей переписи нужен отдельный сервер и база; см. `backend/README.md`.

## Проверки

Автоматически проверяются подтверждение ответа перед изменением рисунка, все варианты выбора, фотографии, возврат и повторный старт, точное восстановление ссылки, размеры экспортируемой картинки, отсутствие шкал и корректность статических ресурсов.

Полный тест перебирает **4 × 4 × 7 × 16 × 11 × 12 = 236 544** пиксельные композиции и проверяет отсутствие совпадений. Быстрый композитор сверяется с обычным рендером. Серверный прототип отдельно проверяется на SQLite, включая повторы и одновременные запросы.

Браузерная проверка мобильного вида и фактического скачивания PNG ещё необходима перед публичным продвижением. Секреты, локальные данные инструментов и `node_modules` в репозиторий не включены.
