# Прототип общего счётчика

Эта папка сохраняет проверенный код серверного счётчика для будущего развития. Он **не подключён к статической версии** и не запускается GitHub Pages.

`finds.ts` принимает Web `Request` и объект с интерфейсом Cloudflare D1 (`prepare`, `batch`). `test-schema.sql` — схема для теста, не автоматически применяемая production-миграция. `tests/counter.mjs` запускает код на SQLite в Node.js 24.

Дедупликация идёт по хешу анонимного идентификатора браузера и ключу котика. GET ничего не записывает. POST вставляет находку и увеличивает счётчик атомарно. Повторы не добавляются, но очистка данных браузера или другое устройство могут создать ещё одну сборку: это не число проверенных уникальных людей.

Для запуска нужны реальная серверная среда, миграции, подключённая база и доступный клиенту API. После этого необходимо настроить допустимый Origin/маршрутизацию, заполнить `statisticsEndpoint` в `src/app.js`, пересобрать `docs` и проверить интеграцию. До этого поле остаётся `null`, и запросы к несуществующему API не отправляются.
